# SANA — Personal Productivity & Focus App

SANA is an ultra-modern, offline-first personal productivity and habit tracking app engineered with Flutter & Riverpod.

## Features

- **Smart Task Management**: Recurring schedules, subtasks, overdue tracking, and priority levels.
- **Dynamic Streak & Habit Tracking**: Real streak calculations, frequency indicators, and celebration animations.
- **Study Material & Notes**: Save links, study documents, tags, pinned notes, and open references with direct system launchers.
- **Personal Journal & Mood Reflection**: Aesthetic reflection notes, mood ratings, tags, and local encryption.
- **System Alarms & Audio Notifications**: Reliable wake locks, full screen alerts, and audible ringers.
- **Theme Studio with 10 Design Systems**: Switch seamlessly between Obsidian AMOLED, Glass Atelier, Paper Journal, Sunset Glow, and custom themes with persistent multi-layer caching.
- **Offline First & Secure**: Encrypted local SQLite persistence with backup/export options. Zero unwanted background leaks.

## Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/ershobhit17/SANA.git
   cd SANA
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run on device or emulator:
   ```bash
   flutter run
   ```
